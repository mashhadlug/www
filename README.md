# مشهدلاگ

این پروژه فورکی از وبسایت **مشهدلاگ** است که از سال ۱۳۸۶ میزبانی می‌شده و به دلیل عدم دسترسی به دامنه اصلی و پراکندگی تیم، دیگر در دسترس نیست. 

هدف از این فورک، صرفاً حفظ و میزبانی محتوای گذشته مشهدلاگ برای ماندگاری و جاودانگی آن است. وبسایت اکنون روی ساب‌دامین [mashhadlug.sudoshz.ir](https://mashhadlug.sudoshz.ir) در دسترس است.
